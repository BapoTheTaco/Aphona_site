Publiceren op GitHub Pages

  1. Klik onderaan op beide downloadknoppen.
  2. Open de GitHub-repository van de website en ga naar de map content.
  3. Vervang activiteiten.json en/of praesidium.json door de nieuwe bestanden en commit de wijziging.
  4. Na de GitHub Pages-deploy staat de wijziging online. Je hoeft geen HTML, CSS of JavaScript te wijzigen.

Foto’s: bij een praesidiumlid of vorig jaar mag je een volledige https-link invullen, of een pad zoals assets/img/huidig/praesidium-2026.jpg wanneer de foto in de repository staat.
